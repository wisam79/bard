## ملخص المشاكل الحرجة المكتشفة

1. **float64 للقيم المالية** - يسبب أخطاء تقريب في الحسابات النقدية
2. **طبقات غير مُدمجة** - Cache، Audit، Crypto موجودة لكن لا تُستخدم
3. **SaleService يتجاوز Repository** - يستخدم `s.db.Transaction()` مباشرة
4. **Cache key generation خاطئ** - `string(rune(page))` ينتج Unicode خاطئ
5. **كلمة مرور admin افتراضية = "admin"** - بدون إجبار تغييرها
6. **generateRandomSuffix في audit.go** - ليس عشوائي فعلياً
7. **CustomerService.Update** - منطق هش للتحقق من القيم الصفرية
8. **بدون CI/CD** - لا GitHub Actions، لا Docker
9. **نقص تغطية الاختبارات** - Service layer و Repository layer ضعيفة
10. **SQL Injection محتمل** - استخدام `LIKE "%"+search+"%"` بدون تنظيف

## المرحلة 1: الأساس المعماري (الأولوية القصوى)

### 1.1 تحويل float64 إلى decimal للقيم المالية
**الملفات**: `internal/domain/*.go`

- إضافة مكتبة `github.com/shopspring/decimal` إلى `go.mod`
- تحويل جميع حقول القيم المالية في Domain من `float64` إلى `decimal.Decimal`:
  - `Product.Price`, `Product.Cost`, `Product.Stock`, `Product.WholesalePrice`, `Product.MinStock`
  - `Sale.Subtotal`, `Sale.Discount`, `Sale.VAT`, `Sale.Total`, `Sale.TotalCost`
  - `SaleItem.Price`, `SaleItem.Quantity`, `SaleItem.Total`, `SaleItem.Cost`, `SaleItem.Discount`, `SaleItem.ReturnedQty`
  - `Customer.Debt`, `Customer.InstallmentDebt`, `Customer.TotalPurchases`
  - `Expense.Amount`
  - `Payment.Amount`
  - `Discount.Value`, `Discount.MinQty`
  - `Shift.StartCash`, `Shift.EndCash`
  - `CashMovement.Amount`
  - `PurchaseOrder.Total`, `PurchaseOrderItem.Qty`, `PurchaseOrderItem.Cost`, `PurchaseOrderItem.Total`
  - `ProductStats.*`, `InvoiceStats.*`, `DashboardStats.*`, `TopProduct.*`
  - `InstallmentPlan.TotalAmount`, `InstallmentPlan.DownPayment`, `Installment.Amount`
  - `InstallmentPlanCalculation.*`
  - `Supplier.Balance`
  - `StockMovement.Qty`
  - `ParkedSale.Total`, `ParkedSale.ItemsCount`
- تحديث Repository layer لاستخدام `decimal.Decimal` مع JSON serialization مخصص
- تحديث Service layer لاستخدام `decimal.Decimal` في جميع الحسابات
- تحديث Frontend types (`types/index.ts`) - الحفاظ على `number` في TypeScript لكن ضمان دقة JSON serialization من Go
- **ملاحظة**: سيتم استخدام custom JSON marshal/unmarshal لـ decimal لضمان التوافق مع frontend

### 1.2 إصلاح Cache Key Generation
**الملف**: `internal/cache/cache.go`

- استبدال `string(rune(page))` بـ `fmt.Sprintf` أو `strconv.Itoa` في جميع الدوال:
  - `GetProductList` (سطر 142)
  - `SetProductList` (سطر 147)
  - `GetSaleList` (سطر 195)
  - `SetSaleList` (سطر 199)
  - `GetRecentSales` (سطر 211)
  - `SetRecentSales` (سطر 216)
  - `GetCustomerList` (سطر 244)
  - `SetCustomerList` (سطر 249)
- إضافة استيراد `"fmt"` و `"strconv"` حسب الحاجة

### 1.3 دمج Cache في Service Layer
**الملفات**: `internal/service/services.go`, `internal/service/sale_service.go`

- حقن `*cache.DashboardCache`, `*cache.ProductCache`, `*cache.SaleCache`, `*cache.CustomerCache` في الـ Services المقابلة
- في `ProductService.GetAll`: التحقق من Cache قبل الاستعلام، وتحديث Cache بعد الاستعلام
- في `ProductService.Create/Update/Delete`: إبطال Cache للمفتاح المناسب
- في `StatsService.GetDashboardStats`: استخدام `DashboardCache`
- في `SaleService.GetAll/GetRecent`: استخدام `SaleCache`
- في `CustomerService.GetAll/GetByID`: استخدام `CustomerCache`
- تحديث `main.go` لإنشاء Cache instances وتمريرها للـ Services

### 1.4 إصلاح SaleService - تجاوز Repository Pattern
**الملفات**: `internal/service/sale_service.go`, `internal/repository/interfaces.go`, `internal/repository/sqlite/sale_repo.go`

- إضافة دالة `ProcessReturnWithStockUpdate(saleID string) (*domain.Sale, error)` إلى `SaleRepository` interface
- نقل منطق المعاملات (transaction) من `SaleService.ProcessReturn` إلى طبقة Repository

- إزالة `db *gorm.DB` من `SaleService` struct
- تحديث `NewSaleService` لإزالة معامل `db`

### 5.1 GitHub Actions
**ملف جديد**: `.github/workflows/ci.yml`

```yaml
name: CI
on: [push, pull_request]
jobs:
  backend:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with: { go-version: '1.24' }
      - run: go test ./... -v -count=1 -race
      - run: golangci-lint run
  
  frontend:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: cd frontend && npm ci
      - run: cd frontend && npm run typecheck
      - run: cd frontend && npm run lint
      - run: cd frontend && npm run test:ci
  
  build:
    needs: [backend, frontend]
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
      - run: go install github.com/wailsapp/wails/v2/cmd/wails@latest
      - run: wails build
```
